## Installation

1. Cloner le dépôt :
```bash
git clone https://github.com/ZahiriAsma/projet-setnance.git
cd projet-setnance
```

2. Installer les dépendances :
```bash
# Frontend
npm install

# Backend Laravel
composer install
```

3. Configurer l'environnement :
```bash
cp .env.example .env
php artisan key:generate
```
Renseigner ensuite les informations de la base de données dans le fichier `.env`.

4. Lancer les migrations puis le projet :
```bash
php artisan migrate
php artisan serve
npm start
```
